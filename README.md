# 동물도감 탐험대 RPG

초등학교 3학년 과학 「동물의 생활」 수업용 Phaser 3 수집형 RPG입니다.

다섯 서식지를 탐험하며 동물을 관찰하고, 퀴즈 배틀을 거쳐 40마리를 도감에 등록할 수 있습니다.

## 실행

```bash
npm install
npm run dev
```

## 배포

`main` 브랜치에 push하면 GitHub Actions가 빌드하고 GitHub Pages에 자동 배포합니다.

## 에셋 크레딧

- Sprout Lands by Cup Nooble
- 오버월드 미니 동물 스프라이트와 도감볼은 프로젝트 자체 제작
- 동물 사진의 상세 출처는 각 원본 데이터의 출처 정보를 따릅니다.
