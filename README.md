# 동물도감 탐험대 RPG

초등학교 3학년 과학 「동물의 생활」 수업용 Phaser 3 수집형 RPG입니다.

다섯 서식지를 탐험하며 동물을 관찰하고, 퀴즈 배틀을 거쳐 40마리를 도감에 등록할 수 있습니다.

## 실행

```bash
npm install
npm run dev
```

## 화면과 비주얼 (G6 고밀도 픽셀아트)

배경·동물·지도 그림은 잎·돌·물결 결이 살아 있는 고밀도 픽셀아트입니다. 학습용 실제 사진은 픽셀화하지 않고 원본 비율과 부드러운 표시를 유지합니다.

- **지역별 전투 배경:** 마을·숲·강가·바다·사막·고산·극지 7종을 `public/assets/detailed-pixel/battle-*.webp`로 두고 `src/world/BattleBackdrops.js`가 고릅니다. 산양은 고산, 북극곰·북극여우·펭귄은 극지를 사용합니다. 그림을 줄일 때는 선형 보간을 써서 잎·돌 결이 뭉개지지 않게 합니다.
- **시작 화면:** 전용 공원 그림(`title-park.webp`)을 화면 전체에 채우고, 위쪽에는 제목 카드, 가운데에는 시작·도감 버튼, 아래에는 안내 문구 판을 둡니다. 안내 문구는 밝은 판 위에 올려 배경 위에서도 읽힙니다.
- **읽기 UI:** 시작 화면·월드맵·도감·퀴즈의 글과 버튼은 `#ui-root`의 네이티브 DOM(`src/ui/ScreenUi.js`)입니다. 종이색 카드와 단단한 테두리·그림자를 사용합니다.
- **첫 화면과 캐릭터:** 시작 화면에서 「모험 시작」 또는 「이어서 모험」을 눌러야 지역 선택 지도로 이동합니다. 저장 기록이 있어도 자동 진입하지 않습니다. 시작 화면에서 도감을 열고 돌아올 수 있으며 Enter·Space도 지원합니다. 플레이어의 기본 몸·색과 닭·소는 Sprout Lands 원본을 유지하고, 포획 축하에는 원본 Teemo 이모트 시트의 32×32 두 프레임을 잘라 재사용합니다.
- **여행 지도:** `detailed-pixel/world-map.webp`의 마을·숲·강과 호수·바다·사막과 설원에 기존 연결 경로를 겹칩니다. 현재 위치와 선택한 목적지는 별개이며, 캐릭터가 경로를 따라 이동한 뒤 해당 지역에 들어갑니다. 가로·큰 화면은 전체 지도를 한눈에 보여 주고, 390px급 세로 화면은 지도를 약 1.5배로 키워 지도 영역 안에서만 좌우로 살펴볼 수 있습니다. 최초 현재 위치와 화면 밖 목적지·이동 마커만 필요한 만큼 보이게 맞추며, 아래 지역 버튼으로도 다섯 곳을 항상 고를 수 있습니다.
- **걷는 지도:** 지역마다 원본 고해상도 그림 한 장을 게임 표시 영역에 맞춰 이어 붙여 타일 반복 없이 그립니다. 원본별 정확한 크기는 provenance 기록을 따릅니다. 통행·수영·문 판정은 그림이 아니라 G5에서 그대로 옮긴 칸 집합(`src/data/world-layout.json`)을 쓰므로, 소품이 막는 자리와 실제 충돌이 어긋나지 않습니다. 잠긴 문만 길 두 칸을 막고 울타리 조각과 「잠김」 표찰을 얹으며, 열면 조각이 사라지고 물빛 도트가 흩어집니다.
- **전투 배치:** 상태 표시, 캐릭터가 서는 전투 영역, 맨 아래 대화·선택 영역을 분리합니다. 플레이어는 왼쪽 아래, 상대 동물은 오른쪽 위에 배치하고 긴 내용은 아래 영역 안에서 스크롤합니다. 관찰 단계는 완료 체크와 현재 단계 테두리를 따로 표시합니다.
- **하트와 기력:** 전투 HUD는 글자 대신 픽셀 하트 3개와 기력 눈금을 그립니다. 잃은 하트는 빈 실루엣으로 남아 몇 개가 남았는지 한눈에 보이고, 남은 하트·기력이 1 이하면 판이 붉게 깜빡입니다. 화면 낭독기를 위해 「나의 하트 2/3」 같은 설명은 그대로 둡니다.
- **포획 결과:** 도감볼은 상대 동물의 그림자 바닥에 착지하며 회전·리사이즈 중에도 접점을 유지합니다. 포획 후 동물이 볼에서 다시 나오고, 실제 사진·사는 곳과 함께 표시됩니다. 플레이어는 원본 두 프레임으로 팔을 들고 정면 눈웃음을 지으며 한 번 10px 점프한 뒤 마지막 웃음 프레임과 제자리로 돌아오고, 「인사하기」로 동물과 인사를 나눌 수 있습니다.
- **하트 소진:** 세 번 틀리면 원본 Teemo 이모트 시트의 32×32 세 프레임으로 짧게 주춤하고 눈을 감은 자세를 유지합니다. Esc로는 나가지 않으며 「탐험으로 돌아가기」를 클릭하거나 그 버튼에서 Enter·Space를 눌러야 탐험으로 복귀합니다. 돌아온 직후에는 같은 동물과 곧바로 다시 부딪히지 않습니다. 실패로 도감·배지가 지급되거나 수집 기록이 줄어들지 않습니다.
- **이동·수영 조작:** 반투명 원형 아날로그 스틱을 360도로 밀어 이동하며, 민 거리에 따라 속도가 달라집니다. 배경판 아래로 주변 환경이 보이되 손잡이와 윤곽은 구분됩니다. 방향키·WASD도 사용할 수 있습니다. 손을 떼거나 화면을 전환·회전하면 스틱이 중립으로 돌아옵니다. 물에 들어가면 원본의 두 자세와 잔물결로 자동 수영하며, 물에서는 최대 속도가 낮아집니다. 물속 동물에게 직접 다가갈 수 있지만 잠긴 문과 울타리는 통과할 수 없습니다.
- **고산 구역:** 특별한 환경을 사막·고산·극지로 구분합니다. 산양은 바위 능선에서만 배회하고, 북극곰·북극여우·펭귄은 극지 구역을 벗어나지 않습니다. 고산 능선은 걸어 다니는 자갈 바닥, 극지 연못은 헤엄치는 열린 물로 그립니다.
- **동물 그림:** 원작(170068d)이 쓰던 아틀라스 5장(around·land·freshwater·special 64×64, sea 72×48)을 그대로 잘라 40종 × 2자세를 씁니다. 전투에서는 오른쪽을 보던 원화 15종만 화면 왼쪽의 플레이어를 향하도록 좌우 반전하고, 왼쪽 20종과 정면 5종은 그대로 둡니다. 탐험 중에는 실제 가로 이동량과 각 원화의 기본 방향을 함께 보고 동물 그림만 좌우 반전하므로 방향을 바꾼 뒤 뒷걸음질하지 않으며, 이름표·그림자·체크 표시는 뒤집지 않습니다. 수직 이동과 멈춤에서는 마지막 방향을 유지합니다. 자홍 배경 키가 섞인 테두리 픽셀은 옮겨 담은 뒤 지워 자홍 테두리가 남지 않게 하고, 모든 텍스처는 최근접 필터로 각진 픽셀을 지킵니다. 도감볼·머리 위 표시는 프로젝트 코드로 그립니다.
- **사진 다시 불러오기와 확대:** 실제 학습 사진은 비율과 원색을 유지하며, 불러오기에 실패하면 「사진 다시 불러오기」로 재시도합니다. 관찰·퀴즈·힌트·포획 사진은 작은 돋보기+ 아이콘이나 사진 전체를 눌러 확대할 수 있고, 확대 중에는 관찰이나 답 선택이 진행되지 않습니다. 화면을 돌려도 사진 전체를 맞춰 보여 주며 닫기·Esc 뒤 원래 사진 버튼으로 초점이 돌아옵니다.
- **완성 보상:** 한 서식지의 8종을 모으면 실제 저장 배지와 다음 지역의 열린 문을 확인형 수여 화면으로 보여 줍니다. 40종과 다섯 배지를 모두 모으면 더 큰 원본 왕관과 「도감 마스터」 칭호를 받고, 왕관·칭호는 탐험 HUD와 도감에 계속 남습니다. 이미 받은 보상은 재접속해도 다시 재생되지 않습니다.
- **검증 범위:** 최초 G6의 586개 후속 점검·197개 캡처, 여섯 기능 및 네 개선 검증은 historical로 보존합니다. `index-BlVsjJNi.js`·`index-LNtj7kOX.css`에서는 새 격리 프로필의 7/8과 39/40 fixture에서 각각 마지막 동물을 정상 관찰→정답→포획해 지역 배지→문 해제와 지역→마스터 보상 순서, 입력 잠금, Enter·Esc 확인, 문 통과, 재접속 영속·재지급 없음, HUD·도감 왕관/칭호와 scene 종료 경쟁을 실제로 확인했습니다. 마스코트 겹침만 고친 최종 `index-CSqT0L_F.js`·`index-DnSChx3o.css`에서는 390×844·844×390·768×850의 지역·마스터 보상, 48px 이상 CTA, 유한한 기본 효과와 감소 모션의 정적 보상·확인 후 이동을 격리 브라우저로 보완했습니다. 같은 최종 번들에서 일반 프로필의 Title→지도→탐험→지도 왕복도 585px 확대 규칙을 유지했고 수집 저장 원문은 그대로였습니다. 최종 이미지 바이트를 직접 판독했고 수치는 보조로만 사용했습니다. 상세 기록은 `artifacts/visual-patch/g6/verification.json`과 `artifacts/visual-patch/g6-followup/verification.json`입니다. 실제 삼성 브라우저·휴대폰 실기·교사 검수·공개 배포 완료를 뜻하지 않습니다.
- **저장:** 기존 `animal-encyclopedia-collected-v1`, `animal-encyclopedia-region-clear-v1`과 동물·지역 데이터, 배지 조건, 문·수영 경계를 유지합니다.

## 배포

`main` 브랜치에 push하면 GitHub Actions가 빌드하고 GitHub Pages에 자동 배포합니다. 이번 비주얼 갱신은 그 배포나 출시 검수를 대신하지 않습니다.

`npm run build` 결과는 `dist/`이며 상대 경로(`base: "./"`)를 사용합니다. 출처 페이지는 `public/credits.html`에서 복사되어 배포 경로의 `credits.html`로 제공됩니다. 저장 형식을 바꾸지 않았으므로 이전 검증 빌드로 되돌릴 때도 같은 오리진의 수집 기록을 유지합니다.

## 에셋 크레딧

- Sprout Lands by Cup Nooble — 흰색 긴 귀 플레이어·수영 자세·닭·소·잠긴 문 울타리, Teemo 이모트 시트의 축하 두 프레임과 실패 세 프레임, Setting menu와 Square Buttons의 UI 테두리 두 조각, Special Icons의 `(0,32)` 별 배지와 All Icons의 `(224,16)` 왕관을 16×16으로 잘라 사용합니다. 비상업 프로젝트용 라이선스 원문은 `public/assets/sprout-lands/sprites/read_me.txt`입니다.
- 고밀도 배경·지도: `public/assets/detailed-pixel/` — 지역 전투 배경 7장, 시작 화면 1장, 여행 지도·도감 숲, 지역 지도 5장. 실제 생성 기록은 [sprout-soft/provenance.json](artifacts/visual-patch/g6/source/sprout-soft/provenance.json)에 있습니다. 사용 도구는 내장 `image_gen.imagegen`이고 정확한 하위 모델 값은 `null`입니다. 이 source 경로는 `artifacts/` 규칙에 따라 Git ignore 대상입니다.
- 동물 그림: `public/assets/generated/animals/` — 원작 아틀라스 5장을 그대로 쓰고, `src/world/AnimalSprites.js`가 48×48 두 포즈로 잘라 담습니다.
- 동물 사진의 상세 출처는 각 원본 데이터의 출처 정보를 따릅니다. 목록: [credits.html](public/credits.html)
