## 0. 한눈에 보기

1. **게임의 뼈대는 좋습니다.**
   - 픽셀아트 세계와 배지로 여는 지역 문
   - 오답 → 힌트 → 재도전 흐름
   - 하트가 다 떨어져도 "다음에 다시 만나요"로 끝나는 부드러운 실패 처리

   세 가지 모두 그대로 둡니다.
2. **가장 큰 UX 문제는 '읽고 넘기기'가 많다는 점입니다.**
   - 동물 한 마리마다 관찰 단계에서 '확인'을 약 5번 눌러야 합니다. 40마리면 약 200번입니다.
   - 퀴즈 1번(사는 곳)은 지금 서 있는 지역이 답을 알려 줍니다.
   - 결과 화면은 다음 목표도, 새로 알게 된 것도 보여 주지 않습니다.
3. **교과서 순서와 게임 지역 순서가 이미 맞습니다.**
   - 교과서: 숲(1차시) → 강 → 바다(2차시)
   - 게임: 마을 → 숲 → 강·호수 → 바닷가

   그래서 새 지역을 만들 필요가 없습니다. 기존 지역 위에 '생태계 층'을 얹으면 됩니다. 특히 강·호수 동물 8마리 중 5마리(왜가리·붕어·다슬기·송사리·메기)가 교과서 강 생태계 그림(pp.38–39)에 그대로 나옵니다.
4. **학습목표 1·2에 필요한 새 메커닉은 4개면 충분합니다.**
   - ① 생태 돋보기: 생물 요소와 비생물 요소를 찾아 나누기
   - ② 지역 생태계 보드
   - ③ 역할 배지와 3바구니 분류: 생산자·소비자·분해자
   - ④ 먹이 연결 수집 → 먹이사슬 잇기 → 먹이그물
5. **가져오지 않을 것도 정했습니다.** 아래는 모두 게임 밖, 곧 교사용으로 둡니다.
   - 손으로 하는 조작: 스티커, 연필로 문지르기, 띠종이 고리
   - 실험관찰 기록
   - 자기평가(최고야/잘했어/아쉬워)
   - 긴 토의 발문
6. **목표 3(생태계 보전)은 받은 교과서 쪽수 밖입니다.** 지금은 어휘만 바꿉니다(공격·도감볼 → 관찰·카메라). 턴제의 긴장감과 잡는 순간의 손맛은 그대로 둡니다.

## 2. 지켜야 할 강점

- **배지를 얻어야 다음 지역 문이 열리는 구조.** 목표가 눈에 보입니다.
- **오답 → 해당 관찰 문단 힌트 → 같은 문제 재도전.** 틀린 직후 바로 고치게 돕는 좋은 형성평가 구조입니다.
- **하트가 0이 되어도 벌 대신 "괜찮아요, 다음 탐험에서 다시 만날 수 있어요"라고 말해 줍니다.**
- **도감의 지역 탭, "???" 잠금 카드, 발견 장소 힌트.** 수집하고 싶은 마음을 만듭니다.
- **"퀴즈는 정답 암기가 아니라 도감에서 본 내용을 떠올리는 학습 흐름"이라는 원칙**(`ObservationBuilder.js` 머리말).
- **오답 보기를 정답 판정과 같은 기준(`movementApplies`)으로 고르는 규칙.** 새 문제 유형에도 그대로 적용합니다(5.6 참고).

- 🟠 **5번째 지역 이름이 네 가지입니다.**
  - 핀: "특별 환경"
  - 경로 버튼·지역명: "특별한 환경"
  - `short` 값: "사막·고산·극지"
  - 지도 대체텍스트: "사막·고산·북쪽 빙하"

- 🟠 **진행 상황이 "0/8" 글자뿐이고, 어느 지역을 골랐는지 잘 안 보입니다.**

  - 정식 지역명을 쓰고, 기본 포커스를 "순서대로 가기"로 옮깁니다.
- 🟢 **지도 크기가 화면에 맞지 않습니다.**
  - 데스크톱에서는 약 700×390으로 작고 여백이 큽니다.

### 3.4 조우·관찰
- 🔴 **관찰이 '읽고 확인'만 반복하는 구조입니다.**
  - 개요 화면과 3단계마다 확인을 눌러야 해서, 동물 한 마리에 약 5번, 40마리면 약 200번입니다.
  - 아이들은 읽지 않고 넘기게 됩니다.

  **→ '관찰 돋보기' 한 화면으로 줄입니다.**
  - 동물 그림에서 빛나는 곳 3개(몸·움직임·사는 곳)를 누르면 한 줄씩 공개되고, 곧바로 퀴즈로 넘어갑니다.
  - 공개한 사실은 퀴즈의 단서 칩이 됩니다.
  - 오답 힌트는 지금처럼 해당 문단을 다시 보여 줍니다(`getHintSection` 유지).
  - 5마리를 넘기면 '빠른 관찰'을 허용합니다.
- 🟠 **자동으로 만든 문장이 반복됩니다.** 위치는 `buildObservationDetails`입니다.
  - `animal.move`가 `lifestyle`과 `habitatLife`에 두 번 들어갑니다. → `habitatLife`에서 `move`를 뺍니다.
  - `appearance`의 둘째 문장("몸을 보호하거나 움직이고 먹이를 찾는 데 쓰입니다")은 40마리 모두 같습니다. → 동물마다 다른 `point`나 `relation`으로 바꿉니다.
- 🟠 **가로 화면에서 아래쪽 약 55%가 비어 있고, 제목이 본문을 되풀이합니다.** 동물 그림을 키워 빈 공간을 관찰 무대로 씁니다.
- 🟠 **휴대폰에서는 패널이 쌓이면서 동물 그림이 사라집니다.**
  - 원인: `layoutStage()`(`QuizBattleScene.js:775–876`)가 전투 연출이 아닐 때 등장인물을 숨깁니다.
  - 휴대폰에서도 동물 그림을 작게라도 화면 위쪽에 고정합니다.
- 🟢 **조사 표기가 어색합니다.**
  - 예: "고양이이(가) 나타났어요", "고양이은(는) 이미…"
  - 조사를 자동으로 고르는 헬퍼 함수가 이미 있습니다(4장 참고).

### 3.5 퀴즈
- 🔴 **Q1(사는 곳)은 지역이 답을 알려 주고, 오답 보기도 너무 쉽습니다.**
  - 예: 강·호수 지역에 서 있는데 사는 곳이 "강이나 호수"인지 묻습니다.
  - 2장 이전: 헷갈릴 만한 이웃 서식지를 오답 보기로 씁니다.
  - 2장 이후: Q1을 '먹이'나 '역할' 문제로 바꿉니다.
- 🟠 **Q1의 단서 칩이 Q2(움직임)의 정답을 미리 보여 줍니다.** 단서 칩에는 지금 문항 유형에 해당하는 사실만 둡니다.
- 🟠 **Q3에 지느러미에 관한 오답 보기가 두 개 들어갑니다.** 같은 속성을 다루는 오답은 1개만 둡니다.
- 🟠 **재도전할 때 보기 순서가 같아서, 내용 대신 위치로 찍을 수 있습니다.**
  - 원인: `QuizBuilder`의 `shuffle`이 문제를 만들 때 한 번만 실행됩니다.
  - 재도전할 때 보기를 다시 섞습니다.
- 🟠 **HUD의 '기력'이 누구 것인지 헷갈립니다.**
  - 아이들은 자기 체력으로 읽기 쉽습니다.
  - 동물 얼굴 옆으로 옮기고, 이름을 '경계심'으로 바꿉니다(5.5 참고).

### 3.7 도감
- 🟠 **'교과서 38쪽' 같은 쪽수 표기가 4-2 교과서와 헷갈립니다.**
  - 예: 무당벌레는 "38쪽"인데, 4-2 교과서 p.38은 강 생태계입니다. 뱀 "40쪽, 45쪽", 도루묵도마뱀 "47쪽"도 마찬가지입니다.
  - 학년·학기를 함께 적습니다. 예: "3학년 38쪽", "4-2 45쪽"
  - 데이터도 `{ grade, page }`처럼 학년과 쪽수로 나눕니다.
- 🟠 **먹이 관계와 역할을 보여 주는 칸이 없습니다.**
  - 역할 배지와 "먹는 것 / 먹히는 것" 행을 넣습니다.
  - 발견한 관계만 보이고, 나머지는 "?"로 둡니다.
- 🟠 **위키백과 외부 링크가 있습니다.**
  - 교과서는 차시마다 '디지털 딸깍'(디지털 활동 수칙)을 넣습니다.

### 3.8 분류 게임
- 🟠 **학습지처럼 느껴집니다.**
  - 제목이 "분류 연습"이고, 브라우저 기본 선택 상자(`<select>`)와 "채점하기" 버튼을 씁니다.
  - 카드를 바구니로 끌거나 탭해서 넣는 방식으로 바꾸고, 카드마다 바로 맞고 틀림을 알려 줍니다.
- 🟠 **틀려도 이유가 나오지 않습니다.** 예: "거미는 다리가 8개예요 → 다리 있음"처럼 이유 한 줄을 보여 줍니다.
- 🟠 **게임 진행과 연결되어 있지 않습니다(저장·보상 없음).** 별 기록을 저장하고 '분류왕' 배지를 줍니다.
- 🟠 **휴대폰에서 바구니가 화면 아래로 밀려 안 보입니다.** 바구니를 화면 하단에 고정합니다.
- 💡 **교과서 1차시(생물/비생물)와 3차시(역할) 분류 활동이 들어가기 가장 좋은 자리입니다.**
  - 지금 `SORT_CRITERIA`는 예/아니요 두 가지로만 나눕니다.
  - 바구니를 여러 개 쓸 수 있는 구조로 넓힙니다(5.4-③ 참고).

## 5. 교과서 흐름 → 게임 설계

### 5.1 설계 원칙
- **차시마다 새 메커닉은 1개만 넣습니다.** 교과서 활동 수만큼 미니게임을 만들지 않습니다.
- **개념어는 아이가 발견하는 순간에 한 번, 굵게, 교과서 표기 그대로 씁니다.**
  - 대상: 생물 요소, 비생물 요소, 생산자, 소비자, 분해자, 양분, 먹이사슬, 먹이그물
  - 먹이사슬·먹이그물은 교과서처럼 붙여 씁니다.
- **학습 행동 하나마다 무언가를 모으게 합니다.** 카드, 연결선, 별, 도장 중 하나가 바로 쌓여야 합니다.
- **교사가 할 일은 게임 밖에 둡니다.** 토의, 자기평가, 스마트 기기 조사, 모둠 발표는 교사용 안내 1쪽으로 뺍니다.

### 5.4 새 기능 5가지

**① 생태 돋보기 — 1·2차시, 목표 1**
- **흐름**
  1. 빛나는 곳(나무·꽃·버섯·돌·흙·물가·해)에 다가가 Space를 누르거나 탭합니다.
  2. 문지르면 카드가 공개됩니다. 예: "부들"
  3. '생물 요소'와 '비생물 요소' 바구니 중 하나로 던집니다.
  4. 맞히면 생태계 보드의 칸이 채워집니다.
- **틀리면:** "흙은 살아 있지 않아요 → **비생물 요소**" 한 줄을 보여 주고 바로 다시 던지게 합니다. 벌점은 없습니다.
- **공기 표현:** 공기는 눈에 보이지 않으므로 '바람 부는 곳'(흔들리는 풀이나 깃발) 오브젝트로 나타냅니다.
- **코드:**
  - `OverworldScene`에 상호작용 오브젝트 추가
  - 새 데이터 파일 `src/data/ecosystem.js`
  - 새 저장 키 `animal-encyclopedia-eco-v1`

**② 지역 생태계 보드와 별 3개 — 2차시**
- **보드 구성**
  - 공통 칸 4개: 햇빛·공기·물·흙
  - 지역 고유 칸: 생산자 2~3개, 분해자 1개, 이미 만난 동물
  - 대상 지역은 마을·숲·강·호수·바닷가 4곳입니다.
- **별 3개**
  - ★1: 동물 8마리. 지금의 배지이며, 문이 열리는 규칙도 그대로입니다.
  - ★2: 생태계 보드 완성
  - ★3: 먹이그물 연결 완성
  - 게임 진행 속도는 지금처럼 유지하면서, 더 하고 싶은 아이에게 목표를 줍니다. 왕관 조건에 ★2를 넣을지는 선택 사항입니다.
- **공통점 발견 연출:** 두 번째 보드를 완성하는 순간 "숲·강·바다 생태계 모두에 햇빛·공기·물·흙이 있어요!"를 보여 줍니다.

**③ 역할 배지와 3바구니 분류 — 3차시, 목표 1**
- **역할 배지:** 모든 카드에 🌱생산자 / 🍽️소비자 / 🍄분해자 배지를 붙입니다. 뒤집으면 교과서 문장 한 줄이 나옵니다.
  - 생산자: "양분을 스스로 만들어요"
  - 소비자: "다른 생물을 먹어 양분을 얻어요"
  - 분해자: "죽은 생물을 분해해 양분을 얻어요"
- **분류 게임 모드 3개**
  - 몸의 특징(지금 있는 모드)
  - 생물 / 비생물
  - 생산자 / 소비자 / 분해자
- **한 판 규칙:** 카드 6~8장, 60초 이내, 연속으로 맞히면 콤보
- **코드:** `SORT_CRITERIA`를 바구니 여러 개를 받는 구조로 넓힙니다. 예: `{ id, label, bins: [...], classify(item) }`

**④ 먹이 연결 수집 → 먹이사슬 잇기 → 먹이그물 — 4차시, 목표 2**
- **연결 수집**
  - 관찰을 마치면 결과 화면에서 이미 만난 생물과의 연결 1~2개에 불이 켜집니다.
  - 예: "붕어 → 왜가리 · 왜가리는 붕어를 먹어요"
  - 아직 못 만난 쪽은 "?"로 남겨 두어 다음 탐험을 하고 싶게 만듭니다.
- **사슬 잇기**
  - 교과서 사슬 **벼 → 메뚜기 → 개구리 → 뱀 → 매** 카드 5장을 순서대로 잇습니다.
  - 화살표는 항상 먹히는 쪽에서 먹는 쪽으로 갑니다.
  - 완성하면 양분 구슬이 화살표를 따라 흘러서, 설명 없이도 방향 규칙을 보여 줍니다.
  - 지도를 고치지 않아도 되는 독립 퍼즐입니다.
- **먹이그물 탭**
  - 교과서 원형 모형처럼 원 둘레에 생물을 배치합니다.
  - 먹이그물은 지역(생태계)마다 따로 만듭니다.
- **'사라지면?' 체험:** 한 번 해 보면 핵심 문장 도장을 찍어 줍니다.
- **새 퀴즈 유형 '먹이':** 예: "왜가리가 먹는 것은?" 확인된 먹이 관계가 1개 이상 있는 동물에만 냅니다.

**⑤ 이야기 훅 2개 — 재미 담당**
- **물총새 프롤로그**
  1. 컷 3장을 보여 줍니다(한 장에 2줄 이하).
  2. 강·호수에서 물총새가 물로 뛰어드는 장면을 보여 줍니다.
  3. 송사리를 관찰하면 "물총새가 찾던 건 작은 물고기!"가 나옵니다.
  4. 이것이 첫 번째 먹이 연결이 됩니다.
- **다람쥐 호위 퀘스트**
  - 숲에서 다람쥐가 플레이어를 따라옵니다.
  - 도토리를 주우면 기운이 오르고, 뱀이 있는 수풀은 돌아서 갑니다.
  - 2분 안에 끝납니다.
  - 4차시 '생각해 보기'("다람쥐는 왜 뱀을 보고 놀랐을까?")에서 이 경험을 다시 떠올리게 합니다.
  - 다람쥐는 이미 `animals.js`에 들어 있습니다.

### 5.5 목표 3(보전) 대비: 어휘만 바꾸고 게임 방식은 그대로

| 지금 | 제안 |
|---|---|
| 관찰 퀴즈 배틀 | 관찰 챌린지 |
| 앗! 야생의 ○○이(가) 나타났어요! | 앗, ○○을/를 발견했어요! (조사 헬퍼 사용) |
| 기력(동물 게이지) | 경계심 😾 → 😺 (잘 관찰할수록 동물이 마음을 엶) |
| 공격 성공! | 관찰 성공! |
| ○○의 헷갈리기 공격! | 앗, 눈치챘어요! |
| 도감볼 던지기! | 📸 관찰 카드 찍기! (셔터·플래시·카드가 떨어지는 손맛은 유지) |
| 이번에는 놓쳤어요 | 다음에 또 만나요 |
| (결과) | 친구는 사는 곳으로 돌아갔어요 · 도감에 기록! |

- **바꾸는 이유:** 야생동물을 공으로 잡는 그림은 생태계 보전과 반대되는 메시지를 줍니다. 잡지 않고 사진을 찍는 탐험(포켓몬 스냅 방식)으로도 모으는 재미는 충분합니다.
- **보전 퀘스트와 실천 카드:** 예를 들어 강 쓰레기를 주우면 수달이 돌아오는 퀘스트입니다. 다음 교과서 쪽수를 받은 뒤 설계합니다.

### 5.6 콘텐츠 정확성 가드레일
- **먹이 관계는 교과서에 나온 것부터 넣습니다.**
  - 교과서 사슬: 벼 → 메뚜기 → 개구리 → 뱀 → 매
  - p.47 먹이그물에 나오는 참나무·쥐·박새
  - 그 밖의 관계는 국립생물자원관 같은 곳에서 확인한 것만 넣습니다.
- **분해자 문제의 정답은 교과서 예(곰팡이·버섯)와 세균만 씁니다.** 지렁이·공벌레·해삼처럼 죽은 생물을 먹는 동물은 자료마다 분류가 다릅니다. 그래서 퀴즈의 정답에도 오답에도 쓰지 않습니다.
- **반려동물(개·고양이)은 먹이그물 퍼즐에서 뺍니다.** 사람이 주는 먹이를 먹기 때문입니다.
- **먹이그물은 생태계(지역)별로 만듭니다.** 바다 생물과 숲 생물을 한 그물에 섞지 않습니다.
- **화살표 방향은 모든 화면에서 '먹히는 생물 → 먹는 생물'로 통일합니다**(교과서 pp.45–46).
- **정답 판정과 오답 보기 고르기는 같은 함수로 합니다.**
  - 먹이 문제나 사는 곳이 여러 곳인 동물(예: 개구리는 강·호수와 논)에서, 다른 정답이 오답 보기로 섞여 들어가는 것을 막기 위해서입니다.
  - `movementApplies`와 같은 원칙입니다.

## 7. 게임성 가드레일 (새 기능 점검표)

- [ ] 말풍선 하나의 글자는 2줄(약 40자) 이하이고, 휴대폰에서도 3줄을 넘지 않는다
- [ ] 동물 한 마리당 반드시 읽어야 하는 탭은 1회 이하이고, 나머지는 선택이다
- [ ] 틀려도 진행된다. 한 줄 피드백을 준 뒤 바로 다시 도전하게 한다
- [ ] 학습 행동 하나마다 눈에 보이는 보상(카드·연결선·별·도장)이 하나 있다
- [ ] 미니게임 한 판은 60~90초이고, 입력 폼·드롭다운·'채점하기' 버튼을 쓰지 않는다
- [ ] 차시마다 새 메커닉은 1개까지만 넣는다
- [ ] 교과서 용어는 발견하는 순간 굵게 한 번 쓰고, 그 뒤로는 같은 표기로 쓴다
- [ ] 토의·자기평가·조사는 게임 밖에 둔다

export const ecoElements = {

  참나무: { kind: "biotic", role: "producer", regions: ["land"] },
  미역: { kind: "biotic", role: "producer", regions: ["sea"] },
  버섯: { kind: "biotic", role: "decomposer", regions: ["around", "land"] },

  세균: { kind: "biotic", role: "decomposer", regions: "all", hidden: true }
};

// [먹히는 생물, 먹는 생물, 생태계] — 화살표 방향과 같은 순서로 적습니다
export const feedingLinks = [
  ["벼", "메뚜기", "field"], ["메뚜기", "개구리", "field"],
  ["개구리", "뱀", "field"], ["뱀", "매", "field"] // 교과서 pp.44–45
  // 강·호수 등 다른 관계는 출처를 확인한 뒤 추가합니다
];

// 정답 판정과 오답 보기 고르기가 함께 쓰는 단 하나의 기준
export function eats(eater, food, eco) {
  return feedingLinks.some(([f, e, r]) => f === food && e === eater && r === eco);
}
